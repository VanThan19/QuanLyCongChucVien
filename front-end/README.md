# Phân Hệ Frontend - Quản Lý Hồ Sơ Cán Bộ, Công Chức, Viên Chức

Hệ thống giao diện Single Page Application (SPA) xây dựng trên nền tảng **React 19 + Tailwind CSS v4 + Vite**.

## 1. Vai trò & Tuyến đường (5 Phân hệ)

- **Quản trị hệ thống (Admin):** `/admin`
- **Quản lý nhân sự (HR Manager):** `/hr-manager`
- **Quản lý đơn vị (Unit Manager):** `/unit-manager`
- **Cán bộ tổ chức (HR Officer):** `/hr-officer`
- **Cán bộ, công chức, viên chức (Employee):** `/employee/ho-so-ca-nhan`

## 2. Hướng dẫn khởi chạy

```bash
npm install
npm run dev
```

Mở trình duyệt: `http://localhost:5173`
